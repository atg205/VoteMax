# Political Orientation Prediction – DALAS Project

## Overview

This project was conducted as part of the DALAS course (Data Science, Learning and Applications), M1 Quantum Information, Sorbonne Université.

## Data Sources

- Politbarometer survey  
- News article scraping  
- Political speeches  
- Party financial data

## Result

A supervised classification model trained on survey data, achieving ~70% accuracy in predicting political leaning.
